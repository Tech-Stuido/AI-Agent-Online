# MB AI Website Features

## Implemented
- Responsive desktop/mobile interface.
- MB AI branding.
- Rounded-square AI face.
- Expressive eyes and mouth.
- Idle, listening, thinking, talking and surprised states.
- Multiple browser chats.
- New chat and clear chat.
- Browser localStorage chat history.
- Quick prompts.
- Enter to send / Shift+Enter for multiline.
- Typing animation.
- Local llama-server health indicator.
- Dark, midnight and light themes.
- Optional browser text-to-speech.
- Browser SpeechRecognition input when supported.
- Touch-friendly mobile controls.
- No API key in the core chat path.
- No cloud model dependency.

## Voice limitation
Browser speech recognition varies by browser and operating system. The button is implemented without adding a cloud AI service, but this does not guarantee offline speech recognition. Fully offline STT and TTS are planned as backend components.
